# Roadmap

Familiar is an experimental project, and its direction is intentionally flexible.

The items below are ideas and likely areas of development rather than a fixed release plan.

## Short-term

- Image support in messages and tools
- More inference backends
- Improved module debugging
- Better packaging for Windows and Linux
- More reusable reference modules

## Possible future work

- Multimodal inference
- File and attachment passing between modules
- Vector-based knowledge storage
- Richer structured record search
- Streaming responses
- Alternative module transports
- Better module discovery and configuration

The roadmap is not a compatibility or delivery commitment. Familiar is primarily an experimental toolkit, and features may change as new use cases appear.
